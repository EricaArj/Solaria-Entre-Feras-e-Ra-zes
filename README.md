# 🌿 Solaria: Entre Feras e Raízes (Em Desenvolvimento)

Solaria: Entre Feras e Raízes é um jogo RPG 3D de mundo aberto focado em sobrevivência, exploração de 5 biomas dinâmicos, construção de base e interação com um bestiário de animais selvagens (lobos, ursos, javalis, coelhos e galinhas). O projeto encontra-se atualmente em fase ativa de desenvolvimento. Desenvolvido com arquitetura modular limpa e otimizado para dispositivos móveis e desktops.

🚀 Descrição Oficial para o Repositório no GitHub

[EM DESENVOLVIMENTO] Jogo RPG 3D de mundo aberto e sobrevivência, com ciclos climáticos, 5 biomas procedurais (Floresta, Deserto, Tropical, Pântano, Ártico), bestiário de animais selvagens e avatar 3D com membros articulados. Desenvolvido para Web e Mobile.

⚙️ Tecnologias Utilizadas

Three.js (r128): Renderização gráfica 3D de alta performance na web.

TailwindCSS: Interface de usuário (HUD, modais e controles touch) moderna e responsiva.

Vanilla JavaScript (ES6+): Arquitetura limpa dividida em módulos independentes (player.js, animals.js, biomes.js).
